# Brag Plan: Path4U workflow

## Rubric and angle
1. Career and learning workspace: discover opportunities, plan study, prepare application material.
2. Most useful claim: your next step becomes a reviewable learning plan, not an automatic job application.
3. Hook: original P-path mark and “Your future. Your path.”
4. Show actual working routed screens and real generated learning results from the protected Preview. Fictional resume and preparation notes only.
5. Duration: approximately 90 seconds. The user explicitly requested a full explained workflow, so this is longer than Brag's normal 15–25 second launch clip.
6. Polished; a calm, practical product walkthrough.
7. Kokoro local AI narration, readable sentence subtitles, quiet licensed music.
8. Share copy: Discover a next step, build a learning plan, and prepare with Path4U.
9. Entry → discovery → question → roadmap → save/flowchart → mind map → local resume review → draft → fair-use explanation.

## Visual identity
LOOK: #080808 ground, #111111 surface, #FFFFFF text, #B8B8B8 utility text; original Space Grotesk Variable and Inter Variable; 1920×1080, 30fps; 1px #444444 frame, 24px corner radius; 200ms entrance, 400ms crossfade; no colored glow.
BANNED: unrelated generated website layouts, fictional provider success, private user records, credentials, neon effects.
